# 科迪 · 抖音插件

Kodi 插件 `plugin.video.douyin` **1.5.12**（Cookie 登录版）。

仓库：[hxw885210-cmd/kodi](https://github.com/hxw885210-cmd/kodi)

## 下载安装包

**[plugin.video.douyin-1.5.12.zip](https://github.com/hxw885210-cmd/kodi/releases/download/v1.5.12/plugin.video.douyin-1.5.12.zip)**

## 1.5.12

- 搜人名（如唐国强）会出用户卡片，并尽量带上作品
- 长按「进入作者主页」不再闪退成「更多信息见日志」
- 刚搜完被抖音限流时会自动再试，不用重启 Kodi
- 综合搜索优先，和网页端更接近

## 装到 Kodi

1. 打开「未知来源」
2. 插件 → 从 ZIP 文件安装 → 选 `plugin.video.douyin-1.5.12.zip`（可覆盖旧版）
3. 用有效 Cookie / sessionid 登录后再搜索
